# 🎓 College Predictor System

This is a comprehensive web-based application designed to help students predict potential colleges based on their scores. The project is built using a full-stack approach including PHP, MySQL, and modern frontend technologies.

## ✨ Features

*   📱 **Fully Responsive Design**: Optimized for all screen sizes using Bootstrap.
*   🔐 **Secure Authentication**: Includes dedicated Sign-up and Login systems.
*   🧠 **Smart Prediction Logic**: Real-time college matching based on user input.
*   📂 **Database Management**: Integrated with MySQL for user data persistence.
*   🎨 **Clean UI/UX**: User-friendly interface with consistent styling.

---

## 📂 Project Structure

| File Name | Description |
| :--- | :--- |
| `login.php` | Handle user authentication and session start. |
| `home.php` | The main predictor dashboard for authorized users. |
| `practice.php` | Practical module for testing prediction logic. |
| `usertable.sql` | Database schema for users and college data. |
| `Home.css`, `Login.css` | Custom styling for the application. |
| `Login.js` | Frontend validation and interactivity. |
